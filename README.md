| 路径 | 说明 |
|------|------|
| `src/studio` | 工作台界面（初始化骨架）：租户 → 工作区 → 素材/资源三级浏览 |
| `src/lite` | Lite 只读陈列站（按 qtclass `src/lite` 惯例）：三级导航 + 上架素材 |
| `docs/intro` | 是什么：定位、三级结构、边界 |
| `docs/user-guide` | 怎么用：操作与约定 |
| `docs/dev-guide` | 怎么开发：架构原则与加功能的判断 |
| `ROADMAP.md` | 阶段路线：探索期 → 验证期 → 正式期 |
