# 创意工作台开发指南

新增界面前先读它。工作台的全部设计逻辑一句话：**三级结构就是全部，界面只做映射。**

## 架构原则

1. **无数据库**：事实源是 git 仓文件（`quanttide-profile-of-creative-work` 的 `quanttide-founder/<工作区>/{images,videos}`）。工作台是这些仓的只读视图加一个上传口，不引入第二份数据。
2. **三级即导航**：租户 → 工作区 → 素材/资源，与磁盘目录一一对应。目录不存在，界面不出现该项；界面不发明目录以外的层级。
3. **上传即提交**：文件写入对应目录后后台执行 git 提交，提交信息用「素材：<文件名>」一类的事实描述。

## 结构

| 路径 | 说明 |
|------|------|
| `src/studio` | 工作台界面（初始化骨架） |
| `docs/intro` | 是什么：定位、三级结构、边界 |
| `docs/user-guide` | 怎么用：操作与约定 |
| `docs/dev-guide` | 怎么开发：本文 |

## 加功能的判断

问它动的是谁：动单个素材的（预览、上传）住素材视图；动工作区的（新增工作区）住工作区列表；动租户的（接入新租户）住租户列表。**不在素材视图上加跨工作区的操作**——那会让三级结构从界面上漏掉。

## 参照

`qtcloud-media` 的 `src/studio` 是同一形态的先例（工作台界面）与 `docs/dev-guide` 体例来源；技术栈随它对齐后再补。
