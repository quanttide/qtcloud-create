# 创意工作台使用指南

## 打开

首屏是**租户列表**：每个租户一行，显示工作区数量。

## 进工作区

点租户进**工作区列表**：每个工作区一行（如职场言情 `urban-romance`、重生言情 `rebirth-romance`），带素材数和最近更新时间。

## 看素材

点工作区进**素材视图**：`images/` 缩略图网格、`videos/` 列表。点缩略图看大图，点视频播放。

## 传素材

把文件拖进素材视图即上传：

- 图片自动落 `images/`，视频自动落 `videos/`
- 归哪个工作区，由你进的是哪个工作区决定——上传前先确认自己在哪个作品里
- 上传即一次 git 提交，改动可在仓的历史里查到

## 约定

- 一部作品的素材只传进它自己的工作区，不要传到租户顶层
- 素材文件名沿用现有习惯（`1_1_进门的对视.png` 这类序号+描述）
- 工作区的增删在仓里做（目录即语义），工作台只展示已存在的
